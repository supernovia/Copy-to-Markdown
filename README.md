# Copy-to-Markdown
Just a little browser extension for chrome. Enjoy &amp; help if you'd like.

## Installation
1. Download/clone this repository
2. Open Chrome/Edge and go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked"
5. Select the extension folder

## Usage
1. Select any text on a webpage
2. Right-click → "Copy as Markdown"
3. Paste anywhere that accepts markdown

Note does not convert images or slack emojis to markdown, but does keep a reference to them.
